# 激活函数：sigmoid、ReLU 与阶跃

> 对应代码：`include/mini_mlmath/activation.h`
> 前置阅读：[感知机原理](perceptron.md)、[逻辑门与决策边界](logic_gates.md)

一个神经元（感知机）做两件事：**线性组合**（`z = w·x + b`）→ **激活**（把 z 变成输出）。激活函数就是第二步的那个函数，它决定神经元"怎么反应"。本库的 `activation.h` 提供两个激活：sigmoid（经典，输出概率）和 ReLU（**现代默认**，CNN/Transformer 全在用），都各自有标量版 + 矩阵版。

## 1. 为什么需要激活函数

如果没有激活（直接输出 z），多层网络就废了——**线性变换的复合还是线性变换**：

```
W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)   ← 还是一层能表达的东西
```

叠多少层都等价于一层。**激活函数引入非线性，是"深度"唯一的意义来源**。

## 2. sigmoid：定义与图像

```
sigmoid(z) = 1 / (1 + e⁻ᶻ)
```

![sigmoid 曲线](images/sigmoid_curve.svg)

三个特征：

- **值域 (0, 1)**：可以当概率看（逻辑回归的输出层就用它）
- **z = 0 时恰好 0.5**：所以 `sigmoid(z) > 0.5 ⟺ z > 0`——和 sign 的决策边界完全一致
- **处处可导、平滑**：这是它比阶跃强的地方（见下）

## 3. 阶跃 vs sigmoid：为什么多层必须换掉 sign

![sign vs sigmoid 对比](images/sign_vs_sigmoid.svg)

| | 阶跃 sign | sigmoid |
|---|---|---|
| 图像 | 台阶：垂直跳变 | S 形：平滑过渡 |
| 输出 | 只有 ±1 两档 | (0,1) 连续 |
| 导数 | z=0 处不存在，其余恒 0 | 处处可导 |
| 适用 | 单层感知机（不反向传播） | 多层网络（要反向传播） |

**关键链条**（我们之前一步步推过的）：

```
要解决 XOR → 必须加隐藏层（多层）
→ 多层要用梯度下降训练 → 梯度靠反向传播算
→ 反向传播用链式法则 → 每层激活必须可导
→ 阶跃不可导 → 换成 sigmoid / ReLU
```

反向传播里，梯度是"怎么改权重"，链式法则是"怎么算梯度"：

```
∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w
        └─损失对输出─┘  └激活对分数┘ └分数对权重┘
                       ↑ 这一项只有可导激活才有——阶跃在这里是 0 或不存在
```

所以 `activation.h` 里 sigmoid 的注释写着"MLP 时代改用可导的平滑激活函数"——不是口味，是链条的必然终点。

## 4. ReLU：现代深度学习的默认激活

```
relu(z) = max(0, z)
```

正数原样放行，负数砍成 0——这是 MLP 之后所有主流网络（ResNet / Transformer / GPT）隐藏层激活的事实标准。求导：

```
relu'(z) = 1    if z > 0
            0    if z ≤ 0    （z=0 处按惯例取 0，是 subgradient 选择）
```

### 三个实操优势（vs sigmoid）

**1) 不饱和 → 缓解梯度消失**

sigmoid 在 z 很大或很小时导数趋近于 0（看图：两端都「贴」在水平线上）。多层网络反向传播时，每层都乘一个 ≤ 0.25 的 sigmoid 导数（最大值在 z=0 处取到 0.25），5 层下来梯度最大只剩 0.25⁵ ≈ 0.001，10 层是 0.25¹⁰ ≈ 10⁻⁶——**浅层权重几乎不更新**。

ReLU 在 z > 0 一侧导数恒为 1，梯度穿过 ReLU 层完全不掉，几十层上百层的网络都能稳定训练。

**2) 计算便宜**

sigmoid 一次要算 `exp(-z)` + 一次除法；ReLU 就一次比较 + 一次取数。**几十倍的开销差距**。CNN / Transformer 每一层都过激活，调用次数是 `batch_size × seq_len × hidden_dim × num_layers`，这部分开销不容忽视。

**3) 稀疏性**

负数输入直接变 0，等价于「随机关掉一半神经元」，带来一些正则化效果，也提高了不同神经元学到不同特征的概率（不会所有神经元都趋同）。

### 缺点：dying ReLU

z < 0 时梯度为 0，**对应神经元再也不会更新**（一旦某次前向把它推成负的，那次反向算出的梯度是 0，权重再也不变）。解决办法：

| 变体 | 负数区行为 | 谁在用 |
|---|---|---|
| LeakyReLU | 0.01·z | 通用备选 |
| PReLU | α·z，α 也学 | 微软的一些工作 |
| GELU | z·Φ(z)，平滑 | GPT / BERT |
| SiLU / Swish | z·sigmoid(z) | MobileNet v3 等 |

本库的 `activation.h` 暂不实现这些，专注最经典的两个：sigmoid + ReLU。

## 5. sigmoid 的数值稳定性：一个必须记住的坑

直接照定义写 `1/(1+exp(-z))`，当 z 很负（如 -1000）时：

```
exp(-z) = exp(1000) = inf        ← 中间值上溢！
1 / (1 + inf) = 0                ← 结果碰巧对，但中间爆了
```

标准做法是**分段**（数学恒等，但中间值永不溢出）：

```
z >= 0:  sigmoid(z) = 1 / (1 + exp(-z))   ← exp(-z) ∈ (0, 1]，安全
z <  0:  sigmoid(z) = exp(z) / (1 + exp(z)) ← exp(z) ∈ (0, 1)，安全
```

这和 `softmax.h` 的"先减最大值"是同一类陷阱：**指数函数天生会爆，实现里必须防**。PyTorch / numpy 都是这么干的。

ReLU 没这个坑——`max` 不会溢出，分支里也不调 `exp`，所以实现极简到一次比较完事。

## 6. 和本库代码的对应

`activation.h` 提供两组重载，编译器按参数自动分派：

```cpp
sigmoid(0.5);                // 标量版：T -> (0,1)
sigmoid(H);                  // 矩阵版：逐元素激活，返回新矩阵
relu(0.5);                   // 标量版：max(0, z)
relu(H);                     // 矩阵版：逐元素激活，返回新矩阵
```

矩阵版就是 MLP 里"每个神经元先加权求和、再过激活"的矩阵化写法。下面两段代码分别演示「老派 MLP」（sigmoid）和「新派 MLP / Transformer」（ReLU）的隐藏层激活：

```cpp
// 老派：sigmoid 作隐藏层激活（80-90 年代的写法）
Matrix<T> H = X * W1.transposed();   // 隐藏层线性分数
Matrix<T> A = sigmoid(H);            // 整层激活
Matrix<T> Y = A * W2.transposed();   // 输出层

// 新派：ReLU 作隐藏层激活（现代 CNN / Transformer 标配）
Matrix<T> H = X * W1.transposed();   // 隐藏层线性分数
Matrix<T> A = relu(H);               // 整层激活
Matrix<T> Y = A * W2.transposed();   // 输出层
```

两段代码结构完全一样，只差激活函数——这就是「激活函数只是非线性插件」的好处：想换 ReLU 就把 `sigmoid(H)` 换成 `relu(H)`，其它不动。

### sigmoid 输出层 vs ReLU 隐藏层：一个常被搞混的点

sigmoid 并没有被淘汰，它现在主要做**输出层**（逻辑回归、二分类网络的最后一层把分数压成概率）。ReLU 不适合做输出层（无界输出，不符合「概率 / 标签」语义），所以现代网络的标配是：

```
隐藏层：ReLU
输出层：sigmoid（二分类）/ softmax（多分类）
```

### 为什么 `logic_gate.cpp` 的 and_gate 用 sign 不用 sigmoid？

单层感知机不反向传播、不需要梯度，经典感知机本来就用阶跃函数——**可导性在那里毫无用处**。所以 and_gate 保留 sign（`scores > 0 ? 1 : 0`），sigmoid / ReLU 留给将来的多层（xor_gate 的隐藏层如果改成可训练版，就要用它们）。这正是"工具要用在需要它的地方"。
